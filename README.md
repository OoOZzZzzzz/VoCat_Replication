# VoCat-Replication
本文记录我完整复刻 **VoCat（喵伴）** 的全过程，主要整理复刻过程中遇到的硬件焊接问题、实操技巧、踩坑细节与解决方案。适合硬件新手、仅拥有焊笔\+风枪简易设备的开发者参考。

## 硬件方案说明

- 本次复刻完全基于官方开源硬件方案开发。官方原版硬件对硬件新手并不友好，板载阻容器件基本均为 **0402 封装**，上手焊接难度高、极易连锡虚焊。

- 后续我计划基于官方方案做二次改版，将所有阻容封装统一升级为 **0603**，降低新手复刻门槛。

- 本文所有焊接操作仅使用 **电烙铁 + 热风枪** 完成，无需加热台等专业设备，硬件条件有限的朋友可直接参考复用全套流程。

### 电源板焊接及注意事项

电源板是整机最核心、最关键的模块，**必须优先焊接、分步测试**，确认无问题后再对接主控板，避免整机烧毁。电源板正面器件焊接难度较低，可最后收尾焊接，重点注意以下细节。

![power_top](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/power_top.jpg?raw=true)

- **开关引脚可以空焊**：正面 ① 位置可空焊，测试供电时，用镊子或金属丝短接对应焊点，即可模拟开关导通效果，完成供电测试。
- **指示灯焊接与极性判断**：② 指示灯双焊点仅焊接左侧焊盘到PCB中间焊盘即可，右侧与 ③ 阳极连通焊接到右侧焊盘。根据芯片手册，指示灯有色带一端为阳极。测试时指示灯不亮属于正常现象，该指示灯仅关联 Type\-C 供电状态。

- **一些技巧：万用表调至通断档，红笔接 ③ 阳极，黑笔探针遍历其余触点，即可快速区分正负极/其他触点的作用了，实在说明都不知道，你可以用这个方法多试试几个触点组合，但最好对照芯片手册**



![power_bottom](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/power_bottom.png?raw=true)

- **Type\-C 接口焊接**：优先焊接背面 ④ Type\-C 接口。该位置焊盘面积大，无需大面积涂锡，仅在边缘均匀薄涂一层锡膏，配合助焊剂用电烙铁拖焊平整；最后再到另一面补焊接口外壳四个固定角。**焊接完成必须用万用表通断档全量测试，以防后面短路烧电脑、烧设备，那就灾难了**。
- **DCDC 电阻替代**：Type\-C 焊接测试无误后，依次焊接 ⑤ 开关芯片、① DCDC 电源电路。原版电路需要 22\.1k 电阻，我忘买对应阻值（就这一处用到，焊接得比较抽象），采用 **20k \+ 1k×2 \+ 100Ω** 串联替代，实测误差极小、供电稳定，完全不影响整机功能，可作为临时替代方案。焊接完成后立即测试整体供电。

- **I2C 通信踩坑（高频报错点）**：最后焊接 ②、③ 器件，其中 ② 为是这部分电路最容易出问题的地方。这个芯片与主控间有 **I2C 通信**，但不影响基础供电。故**代码下载后，若终端持续报 I2C 通信错误，优先排查该芯片焊接虚焊、损坏问题。我复刻时长期被该报错困扰，反复排查主控外设无果，最终确认是该芯片焊接问题，建议大家重点检查、提前避坑，多买点这个芯片备用**。



### 主控板焊接和注意事项

主控板优先焊接顶部接口，再焊接底部核心元器件。底部核心芯片耐高温差，长时间高温吹风极易损坏，优先焊顶部接口可规避器件烧坏风险。

无加热台可采用此方案：焊盘均匀涂抹锡膏，热风枪调至 **300~330℃** 从 PCB 底部均匀加热，手动微调接口位置，待锡膏完全融化即可定型固定。

![main_top](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/main_top.jpg?raw=true)

- **LCD 屏幕接口**：板载 ①、② 两个屏幕接口，仅需焊接 ① 即可。② 焊接难度极高、极易连锡，且无实际使用必要，建议直接空焊，减少返工问题。
- **接口焊接工艺**：在 ① 接口焊盘均匀涂抹锡膏，可热风枪**底部吹融**或电烙铁直焊；焊接完成后务必用电烙铁二次修整，保证每个焊盘上锡均匀、无堆锡、无虚焊，提升一次成功率。最后补涂助焊剂，既能固定接口不偏移，也能让引脚与焊盘充分贴合。
- **屏幕接线方向（关键）**：① 接口接屏幕排线务必遵循 **白线朝上，金属触点朝下**，严禁接反；③ 器件焊接注意对位方向；FPC 排线金属触点朝外，方向错误会导致屏幕不亮、器件烧毁。
- **电池接口**：④ 电池接口放在最后焊接。必须先完成电源板测试、确认供电正常无误后，再按照板载丝印对应正负极接线，杜绝反接烧板。
- **天线配置**：⑤ 位置我采用外接天线版本主控，信号稳定性更好，更推荐大家使用；内置天线版本可根据个人需求选择。



主控板焊接最大难点为背面 **QFN 封装芯片**，该部分器件主要负责音频解码与音频播放功能。整块主控板架构简洁，仅集成主控、音频、陀螺仪三大核心外设，设计合理性很高。

![main_bottom](https://github.com/OoOZzZzzzz/VoCat-Replication/blob/main/doc/image/main_bottom.jpg?raw=true)

- **分步焊接校验**：优先用热风枪焊接 ①、③ 器件，再用电烙铁焊好 ⑧ 排针；对接电源板供电，**先接屏幕、下载程序，确认屏幕正常点亮后，再继续后续焊接**。
- **防误焊保护**：屏幕接口是整块板子最难焊、最易出问题的位置，前期校验完成后，后续**焊接需用锡纸（注意购买好锡纸卷）完整包裹 ⑧ 排针，防止高温烫坏、短路**。
- **运放与供电测试**：包裹保护完成后，用热风枪+锡膏焊接 ② 运放，焊接完成后立即做基础供电测试；以上部分供电由电源板提供，测试无误后再进行下一步。
- **音频供电焊接**：焊接 ⑦ 音频独立供电模块，使用万用表测试供电电压。地线接主控外壳即可，VCC 可在顶部 ③ 端子测量，电压稳定在 3.3V 即为正常，可继续完成剩余器件焊接。
- **音频芯片焊接技巧**：沿用屏幕接口焊接思路，区别是**热风枪从芯片上方加热**（底部器件已焊好，底部吹风易损坏已焊元件）。以 **先焊芯片、后焊外围阻容** 的顺序，镊子微调芯片对位、按压固定，清理多余锡膏，最后用电烙铁修整引脚。如图中 ⑥ 位置单角连锡无需处理，该位置为芯片供电引脚，不影响功能与稳定性。



最后实在担心焊接出问题：相对来说低成本的方法就是比较容易出问题的地方，发板前让厂家代工焊接好这部分：**屏幕接口，Type_C接口，BQ27220YZFR芯片等**
