## 硬件方案说明

- 本次复刻完全基于[官方开源硬件方案](https://oshwhub.com/esp-college/echoear)制作，直接打板制作焊接。所有焊接操作仅使用 **电烙铁 + 热风枪** 完成，无需加热台等专业设备，硬件条件有限的朋友可直接参考复用全套流程。
- 在复刻过程中还是遇到了很多困难，目前已将硬件焊接顺序、其中可能涉及到的坑、注意事项等等都总结在 **hardware** 中的[说明文档](hardware\readme.md)中



## 软件代码说明

- 此次软件 **小智AI源码2.4.2** 进行二次修改
  - 仅把**VoCat（喵伴）** 相关部分保留，删去了其他的开发板，删去相应文件，以供 **VoCat** 开发者二次开发。
  - 删除相应配置，默认开发版为 **VoCat** 并且配置好相应选项，下载即可烧录成功，默认为更丰富的表情，如图所示，如若想修改可以参考代码中对应文档修改成你想要的风格。
  - 其次删除多余组件，与本开发板无关的组件都被删除，减小工程体积。
  - **⚠️ 最重要强调** IDF版本是 6.0.2，如果使用其他版本（如5.5.x）可能会出现许多莫名其妙的问题（不要问我为什么）。
